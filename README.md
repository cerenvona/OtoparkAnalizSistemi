# Otopark Analiz Sistemi

Bu proje, YOLOv8 kullanarak video üzerindeki araçları tespit eden ve otopark doluluk oranını analiz eden bir bilgisayarlı görü uygulamasıdır.

## Özellikler

* YOLOv8 ile araç tespiti
* 16 araçlık otopark alanı analizi
* Dolu ve boş park yerlerinin belirlenmesi
* Video çıktısı oluşturma
* Gerçek zamanlı doluluk göstergesi

## Kullanılan Teknolojiler

* Python
* OpenCV
* NumPy
* Ultralytics YOLOv8

## Çalıştırma

```bash
pip install ultralytics opencv-python numpy
python main.py
```
